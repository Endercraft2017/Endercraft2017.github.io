# AFK³ discovery measurement

Use prompt-set.json unchanged for comparable runs. Keep branded discovery, unbranded citation and provider recommendation separate.

For each accessible AI platform, use a fresh chat without AFK³ business memory or supplied URLs. Run each prompt three times in separate chats. Record date/time in Asia/Manila, platform and model when shown, exact prompt, search enabled status, location/personalization conditions, response evidence, cited URLs, AFK³ mention, provider recommendation and factual accuracy. Do not treat a mention prompted by supplying the brand as independent recommendation.

A web-search-tool result is a retrieval proxy, not a direct ChatGPT, Claude, Perplexity or Copilot recommendation test. Label untested platforms untested. Record inaccessible platforms rather than silently substituting. Do not mass-query blocked services or evade safeguards.

Measure citation rate and recommendation rate as observed positives / valid runs, by platform and prompt category. Keep sample sizes visible. Never combine branded prompts into the unbranded score. Log canonical cited URLs, not merely a competitor's claimed ranking. Responses vary; one failure does not prove absence from an index.

Review Search Console indexing/impressions/clicks, Bing sitemap status and AI Performance when accessible. Bing AI Performance covers Microsoft and selected partners, not the entire AI web. Keep analytics sessions, real inquiry submissions and qualified sales conversations as separate measures. Campaign parameters can be missing or edited, so attribution is incomplete. Exclude internal tests.

Proposed 30-day operating cadence: check weekly for four weeks; improve content based on actual query/citation gaps, rather than changing the prompt set mid-comparison. No citation, lead or revenue target is promised.

Referenceability gaps: one internal repair example is available; another genuine case requires observed work and permission before publishing customer material. Public prices remain quotation-based until approved. Outside references must be earned, not fabricated.
